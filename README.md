# 💖 Doki Doki Translation Club

The front-end for the Doki Doki Translation Club team's website. You can check the backend [here](https://github.com/isneiki/Doki-Doki-Translation-Club-Back).

## 🔨 Technologies

- React
- React Router
- Javascript
- Tailwindcss
- Vite

## 🚀 Features

- Admin panel to easy add new translations
- Clean and concise ui to find and download translations

## 💡 The process

I found a group of translators that had a problem they didn't already notice: their actual website. It was a mess: no routing system, no admin panel, no database, and worst of all: their UI. They needed a fresh restart, a place where they could _easily_ add all their translations and mods. That's when I entered. I spent a week working on their brand new website, fresh clean and free. It started with a simple react.js landing page, then I added routing systems, then search engines, and then I was learning back-end and started my journey as a Full-Stack Web Developer.

## 🏃 Running the Project

1. Clone the repository
2. Install dependencies using `npm install`
3. Run development server: `npm run dev`
4. Open `localhost:5173` in your browser
5. (optional) if you want working admin panel, setup the [back-end](https://github.com/isneiki/Doki-Doki-Translation-Club-Back)
6. (optional) set VITE_SERVER= var in your .env pointing to where your back-end server is hosted.

## 📜 What I learned

- Creating routes with react-router-dom
- Back-end endpoints with ExpressJS
- Database integration with SQLite
